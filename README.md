# OOP

## Library Management System

### About the Project

Library Management System is a Python project developed using Object-Oriented Programming (OOP) concepts.

The project allows users to manage books and students, search for books and students, borrow books, and return borrowed books through a menu-based system.

### Features

- Display all books
- Display all students
- Search books by ID
- Search students by ID
- Borrow books
- Return books
- Check book availability
- Handle invalid input using try-except

### Menu Options

| Option | Description |
|---|---|
| 1 | Show Books |
| 2 | Show Students |
| 3 | Search Book |
| 4 | Search Student |
| 5 | Borrow Book |
| 6 | Return Book |
| 0 | Exit |

### How to Run

Run the following command in the terminal:

```bash
python main.py
```
